# Good Old Days

We read View Source like a textbook.

We named our servers, and we were sad when one died.

We spent an afternoon centering a div.

We wrote YAML until midnight, and one space broke it.

None of it was efficient. All of it was ours.

Now one sentence is enough.

I miss the good old days. Strongly.
